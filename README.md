# DESCRIPTION

The Advanced Encryption Tool is a Python-based cybersecurity project developed to securely encrypt and decrypt files using modern cryptographic techniques. The tool helps protect sensitive information from unauthorized access by converting readable data into encrypted format using secure encryption algorithms.

This project uses the `cryptography` library and implements encryption through the Fernet module, which provides secure symmetric encryption based on AES standards. The application allows users to generate a secret key, encrypt files, and decrypt them back to their original form using the same key.

The project demonstrates practical implementation of cryptography concepts and secure file handling in Python.

# HOW THE TOOL WORKS

1. User generates a secret encryption key
2. User selects a file for encryption
3. The file content is encrypted securely
4. Encrypted data replaces the original content
5. User can decrypt the file using the same key
6. Original file content is restored
